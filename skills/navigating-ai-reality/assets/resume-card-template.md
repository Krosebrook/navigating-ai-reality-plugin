# 7-Pillar Extended Mind Session Resume Card

Use this portable Markdown card so phone calls, context switches, or cloud outages never wipe out your working memory ([The Extended Mind Doc](https://docs.google.com/document/d/1YMRZeI8BUN-pXQo3LAJxvUWFqgk_ccmqUWoprtOMFKQ)):

| Pillar | Field | Entry |
| :--- | :--- | :--- |
| **1. Capture** | Timestamp & Trigger Event | `2026-11-05 09:00 — Initial intake` |
| **2. Externalize** | Root Problem & Causal Trunk | `Define the core mechanism or bottleneck in 1 sentence` |
| **3. Externalize** | Verified Actions Completed | `List steps already completed and verified` |
| **4. Restore Context** | Exact Next Step (10-Sec Resume) | `State the exact single action to take upon returning` |
| **5. Remind** | Boundary / Wake Trigger | `Specify the event or deadline that triggers follow-up` |
| **6. Verify (Hard Gate)** | 3-Item Closure Checklist | `[ ] Math/Numbers Checked  [ ] Primary URLs Linked  [ ] Counterexample Tested` |
| **7. Escalate** | Human Specialist Handoff Rule | `Specify when to pause AI and call a licensed human expert` |
